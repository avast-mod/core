The game ships the regular weight of fs Tahoma 8px. The bold and italic versions match it pixel for pixel and are used for bold and italic text in mod READMEs; the adaptations are shared under the same license. They are made by `make_bold.py` and `make_italic.py` in the installer repository. Cozette draws code in READMEs at its native 13 px size.
