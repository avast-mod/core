# <img src="icon.png" width="32" height="32" alt=""> AVaSt Core

The in-game side of AVaSt for **Antivirus Survivors 2003 Professional**. Open **AVaSt** from the start menu to see your mods, read about them and update them.

Logs and crash reports go to `GDPatch/avast/logs` and `GDPatch/avast/reports`.

Core is built on the [AVaSt API](https://github.com/avast-mod/api) and needs it installed next to it.
